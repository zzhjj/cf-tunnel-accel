外部域名：手动 DNS（仅 CLI）

外部域名不属于当前账户的 zone。交互式 CLI 需要 stdin 等待 DNS 确认，控制台仅提供说明，不提交外部 DNS 任务。

  1. 在终端加载与所选配置相同的环境，先执行 cf-tunnel-accel env 核对配置来源，再执行 cf-tunnel-accel domains。
  2. 运行 cf-tunnel-accel add app.example.com http://127.0.0.1:8080 --external。
  3. 按 CLI 输出在域名所属 DNS 平台手动添加 DCV 验证记录及 DNS-only CNAME；等待生效后回终端确认，完成 HTTPS 验收。
  4. 外部路由的 DNS 切换或删除同样需要在 DNS 平台手动处理；UI 不替代这些步骤。

流程可能写入 Tunnel / SaaS，失败时查看实际状态与 CLI 回滚输出；多服务变更不是跨服务事务。

恢复步骤

  1. 在相同配置环境执行 cf-tunnel-accel env，核对 account、Tunnel UUID、辅助域、config 与 service 的来源。
  2. 缺配置时执行 cf-tunnel-accel init，按提示创建自己的配置；依赖缺失按上方检查结果安装。
  3. 配置凭据并核对 API 权限后重新检查环境。凭据内容不应填入路由或任务日志。
  4. 无 systemd 时使用 CLI / UI 前台运行；不要将未启动的系统服务视为正常。
